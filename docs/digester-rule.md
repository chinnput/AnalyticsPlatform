# Digester Rule v1

## Tag

B1–B4 = `PPPC_DP_Cooking.Bk_Discharge_FinalTime_Press1_Status` — ค่าจริงมีแค่ **0 หรือ k**

## กฎ

1. ดึง status ด้วย **interval ที่เลือก** (1m / 5m / 15m / 1h / 1d) — 1m ละเอียดสุด
2. เทียบแต่ละ tag กับ **k ของตัวเองเท่านั้น**: `Bk == k` = active · อื่นๆ (รวมค่าใกล้เคียง เช่น B2 = 1.95) = **ไม่ active**
3. ตัดสินรายจุด:

| กรณี                   | ผล      |
| ---------------------- | ------- |
| active หม้อเดียว        | **Dk**  |
| ไม่มีหม้อ active        | **0**   |
| active มากกว่า 1 หม้อ   | **NaN** |

ตัวอย่าง: B1=1, B2=0.2, B3=2.1, B4=2 → **D1** (B4=2 ≠ 4 → ไม่ active)

> D0 = "ไม่มีหม้อยืนยัน" (รวมช่วงที่ PI interpolate) — ไม่ใช่ "เครื่องหยุด"
> interval หยาบ (เช่น 1h) = ดูแค่จุดเดียวต่อชั่วโมง → อาจพลาด batch สั้น

## ห้าม

- `round()` หรือเช็คแค่ "เป็นจำนวนเต็ม"
